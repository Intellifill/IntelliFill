1. **Screenshot Capture Instructions** — step-by-step guide for the user to capture screenshots of the production build loaded in Chrome:
   - Load production build: `chrome://extensions` > Developer Mode > Load Unpacked > select `extension-v2/.output/chrome-mv3/`
   - Navigate to a sample form page (suggest: a government form, job application, or any multi-field form)
   - Capture 3 screenshots at 1280x800 resolution:
     a. Popup UI showing logged-in state with profile loaded
     b. Autocomplete dropdown appearing on a form field
     c. Form fields filled after Alt+Shift+F keyboard shortcut
   - For Firefox: same captures but load `extension-v2/.output/firefox-mv2/` via `about:debugging`
   - Save screenshots as PNG files in this directory

2. **Chrome Web Store Submission Checklist:**

   ```
   Pre-submission:
   - [ ] Developer account registered at https://chrome.google.com/webstore/devconsole ($5 fee)
   - [ ] Privacy policy live at https://intellifill.com/privacy (verify with curl)
   - [ ] Screenshots captured (at least 1, recommended 3) at 1280x800 or 640x400
   - [ ] Production zip built: extension-v2/.output/intellifill-extension-2.0.0-chrome.zip

   Submission steps:
   1. Go to https://chrome.google.com/webstore/devconsole
   2. Click "New Item" > Upload zip: extension-v2/.output/intellifill-extension-2.0.0-chrome.zip
   3. Store listing tab:
      - Description: paste from extension-v2/store-listing/chrome-description.md (Detailed Description section)
      - Screenshots: upload from extension-v2/store-listing/screenshots/
      - Category: Productivity
      - Language: English
   4. Privacy tab:
      - Single purpose: paste from permission-justification.md (Single-Purpose Description section)
      - Privacy policy URL: https://intellifill.com/privacy
      - Data use disclosures: fill per permission-justification.md (Data Use Disclosure section)
      - Host permissions justification: paste from permission-justification.md (Why We Need Host Permissions section)
   5. Click "Submit for Review"

   Expected review time: 1-7 business days (longer for <all_urls> permissions)
   ```

3. **Firefox AMO Submission Checklist:**

   ```
   Pre-submission:
   - [ ] Mozilla account created at https://addons.mozilla.org/developers/ (free)
   - [ ] Privacy policy live at https://intellifill.com/privacy
   - [ ] Screenshots captured (at least 1)
   - [ ] Production zip: extension-v2/.output/intellifill-extension-2.0.0-firefox.zip
   - [ ] Source zip: extension-v2/.output/intellifill-extension-2.0.0-sources.zip

   Submission steps:
   1. Go to https://addons.mozilla.org/developers/
   2. Click "Submit a New Add-on"
   3. Upload: extension-v2/.output/intellifill-extension-2.0.0-firefox.zip
   4. When asked "Do you need to submit source code?": YES
      - Upload: extension-v2/.output/intellifill-extension-2.0.0-sources.zip
      - Reviewer notes: "Build: cd extension-v2 && npm install && npm run build:firefox"
   5. Listing details:
      - Summary: paste from firefox-description.md (Summary section)
      - Description: paste from firefox-description.md (Description section)
      - Screenshots: upload from extension-v2/store-listing/screenshots/
      - Privacy policy URL: https://intellifill.com/privacy
   6. Click "Submit Version"

   Expected review time: 1-5 business days
   ```
