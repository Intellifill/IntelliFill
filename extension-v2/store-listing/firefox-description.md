# Firefox Add-ons (AMO) Listing — IntelliFill

## Summary

IntelliFill is a smart form autofill extension that fills web forms using your stored profile data, extracted from documents you upload at app.intellifill.com.

---

## Description

Stop retyping the same information on every website. IntelliFill detects form fields on any web page and fills them instantly with AI-matched profile data from your uploaded documents.

### How It Works

1. Upload your documents (passport, driver's license, resume, etc.) at app.intellifill.com
2. Our AI extracts your information and builds a structured profile
3. On any website with a form, IntelliFill detects input fields and suggests matching values
4. Accept suggestions from the autocomplete dropdown, or press Alt+Shift+F to fill all fields at once

### Features

- **AI field detection** — Automatically identifies form fields and matches them to your stored profile
- **Autocomplete dropdown** — See smart suggestions as you click into any field; pick the right value in one click
- **Fill All shortcut (Alt+Shift+F)** — Fill every detected field on the page in a single keystroke
- **Popup dashboard** — View your profile summary, enable/disable autofill, and manage settings from the toolbar icon
- **Privacy-first** — Only form field metadata is sent to our servers for AI matching; no page content, browsing history, or typed values are collected

## Reviewer Notes

### Build Instructions

The extension is built with [WXT](https://wxt.dev) (a modern browser extension framework).

To build the Firefox version from source:

```bash
cd extension-v2
npm install
npm run build:firefox
```

The output will be in `extension-v2/.output/firefox-mv2/`.

To produce a distributable zip:

```bash
npm run zip:firefox
```

**Framework:** WXT (wxt.dev) handles cross-browser manifest generation and build tooling. The source uses the WXT storage API (`wxt/storage`) which wraps `browser.storage.local`.

**Manifest version:** Firefox MV2 (generated by WXT from the same source as the Chrome MV3 build).

**Entry points:**

- `entrypoints/background.ts` — Service worker / background script
- `entrypoints/content.ts` — Content script injected on all pages for field detection
- `entrypoints/popup/` — React popup UI (built with Vite)
