## Detailed Description

IntelliFill is a smart form autofill extension that fills web forms using the profile data extracted from documents you have uploaded. Stop retyping the same information on every website — IntelliFill detects form fields and fills them in seconds.

### How It Works

1. Upload your documents (passport, driver's license, resume, etc.) at intellifill-web.vercel.app
2. Our AI extracts your personal information and builds a structured profile
3. On any website with a form, IntelliFill detects input fields and suggests matching profile data
4. Accept suggestions from the autocomplete dropdown, or press Alt+Shift+F to fill all fields at once

### Features

- **AI field detection** — Automatically identifies form fields and matches them to your stored profile data
- **Autocomplete dropdown** — See smart suggestions as you click into any field; pick the right value in one click
- **Fill All shortcut (Alt+Shift+F)** — Fill every detected field on the page in a single keystroke
- **Popup dashboard** — View your profile summary, enable/disable the extension per session, and manage settings from the toolbar icon
- **Privacy-first** — Only form field attributes (not page content or form values you type) are sent to our servers for matching; your data is never sold or shared

### Permissions

IntelliFill requests access to all websites (`<all_urls>`) because web forms exist on any website — job applications, checkout pages, government portals, signup forms. The extension cannot know in advance which sites you visit, so broad host permission is required to detect and fill fields wherever you need it. Only form field metadata (input names, labels, types, placeholders) is ever read — not page content, cookies, browsing history, or any values you type.
